# Toko Online UMKM Sekar Jagad Solo (HO-3 s/d HO-6)

Aplikasi toko online sederhana untuk studi kasus Form Handling: Pencarian (GET), Filter Kategori, Validasi Input Formulir, Penyimpanan JSON, Pola PRG (Post/Redirect/Get), dan Rekap Daftar Pesanan.

## Cara Menjalankan
1. Nyalakan Laragon (**Start All**).
2. Akses via browser:
   - Katalog Utama: `http://localhost/p09_toko_umkm/` atau `http://p09_toko_umkm.test`
   - Form Pemesanan: `http://localhost/p09_toko_umkm/pesan.php`
   - Rekap Pesanan: `http://localhost/p09_toko_umkm/daftar-pesanan.php`
